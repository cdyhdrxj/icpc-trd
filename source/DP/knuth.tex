\subsection{Оптимизация Кнута}

Ускоряет ДП на отрезках с $O(n^3)$ до $O(n^2)$, если оптимальный разделитель монотонен.

Для перехода
\[
dp[l][r] = \min_{l \le k < r}
\bigl(dp[l][k] + dp[k+1][r]\bigr) + w(l,r)
\]
обозначим через $opt[l][r]$ значение $k$, на котором достигается минимум.

Для $a \le b \le c \le d$ функция стоимости $w$ должна удовлетворять условиям четырёхугольника и монотонности по включению интервалов:
\begin{enumerate}
    \item $w(a,c)+w(b,d) \le w(a,d)+w(b,c)$
    \item $w(b,c) \le w(a,d)$
\end{enumerate}

При выполнении этих условий:
\[
opt[l][r-1] \le opt[l][r] \le opt[l+1][r]
\]

Поэтому вместо перебора всех $k$ достаточно проверять:
\[
k \in [opt[l][r-1],\,opt[l+1][r]]
\]

Базовые случаи: $dp[i][i]=0,\ opt[i][i]=i$

Вычислять интервалы нужно по возрастанию длины.
